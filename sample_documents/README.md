This folder contains synthetic policy and internal-guideline documents used to test the ClaimIQ document-ingestion and RAG pipeline.

## Documents

1. `01_motor_comprehensive_policy.txt`
2. `02_health_hospitalization_policy.txt`

## Purpose

These documents are used to validate:

- Document upload
- Text extraction
- Document chunking
- Embedding generation
- Vector-database storage
- Semantic top-k retrieval
- LLM answers with source citations
- No-match handling
- Inactive-document exclusion

## Disclaimer

All documents in this folder contain synthetic demonstration content. They are not real insurance contracts or company documents.
